# История изменений

## 1.1.0 — 2026-10-30

- Forbidden Magic и Thaumic Energistics включены в общий цикл сборки, проверки и релиза suite всех шести модов.

- ID загрузчика NeoForge: `thaumcraft_aop`; namespace контента `thaumcraft`, существующие конфиги и обнаружение интеграций сохранены.

- Автоматическая сборка зависимостей AOP из исходников в CI с проверкой ревизий и хешей JAR, без ручных переменных архива.

- Публичные API для Forbidden Magic и Thaumic Energistics: операции с эссенцией в предметах, проверка сканирования, точный расход вис, связанные исследования, экипировка/работа/визуальное состояние големов, симметрия матрицы, cooldown фокусов и молнии узлов.
- Minecraft 1.21.1, NeoForge 21.1.166, Java 21. Локальные сборки и приёмка отделены от публикации.
- Минимальная поддерживаемая NeoForge: 21.1.166. Curios: 9.5.0+1.21.1.
